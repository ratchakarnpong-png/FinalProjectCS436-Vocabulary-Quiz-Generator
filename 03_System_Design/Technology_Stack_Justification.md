# **เหตุผลที่เลือกใช้เครื่องมือ (Technology Stack Justification)**

ในการพัฒนา **Vocabulary Quiz Generator** ทีมผู้พัฒนาได้เลือกใช้เทคโนโลยี Web Stack พื้นฐาน (HTML, CSS, JS) โดยมีเหตุผลสนับสนุนดังนี้:

### **1\. HTML5 (HyperText Markup Language)**

* **เหตุผล:** ใช้สร้างโครงสร้างหลักของหน้าเว็บ เนื่องจากเป็นมาตรฐานสากลที่ Web Browser ทุกตัวรองรับ ทำให้ผู้ใช้งานสามารถเปิดโปรแกรมได้ทันทีโดยไม่ต้องติดตั้งซอฟต์แวร์เพิ่มเติม (Zero-installation)

### **2\. Tailwind CSS (CSS Framework)**

* **เหตุผล:** เลือกใช้ Tailwind CSS แทนการเขียน CSS แบบปกติ (Vanilla CSS) เพราะ:  
  * **ความรวดเร็ว (Speed):** สามารถจัด Layout และตกแต่งหน้าตาได้เร็วกว่าด้วย Utility classes  
  * **ความสวยงาม (Aesthetics):** มี Design System ที่ทันสมัย ทำให้หน้าตาโปรแกรมดูสะอาดและเป็นมืออาชีพ  
  * **Responsive Design:** รองรับการแสดงผลทั้งบนหน้าจอคอมพิวเตอร์และมือถือได้ง่าย

### **3\. JavaScript (ES6+)**

* **เหตุผล:** เป็นหัวใจหลักในการจัดการ Logic ของระบบ  
  * **File API:** ใช้สำหรับอ่านข้อมูลจากไฟล์ .csv หรือ .txt ที่ผู้ใช้อัปโหลดเข้ามา (Client-side parsing) โดยไม่ต้องส่งข้อมูลไปประมวลผลที่ Server  
  * **Randomization Logic:** ใช้เขียนอัลกอริทึมในการสุ่มโจทย์และสุ่มตัวเลือกหลอก (Distractors) เพื่อให้การทำแบบทดสอบแต่ละครั้งไม่ซ้ำกัน  
  * **DOM Manipulation:** ใช้ในการอัปเดตหน้าจอ (เปลี่ยนโจทย์, เปลี่ยนสีปุ่มเมื่อตอบถูก/ผิด) แบบ Real-time โดยไม่ต้องรีเฟรชหน้าเว็บ
