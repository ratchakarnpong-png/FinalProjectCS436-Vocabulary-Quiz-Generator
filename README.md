# **📚 Vocabulary Quiz Generator (Final Project)**

**ระบบสร้างแบบทดสอบคำศัพท์อัตโนมัติ** เว็บแอปพลิเคชันที่ช่วยให้การท่องศัพท์ไม่น่าเบื่ออีกต่อไป รองรับการโหลดไฟล์คำศัพท์ส่วนตัวและมีระบบสุ่มตัวเลือกหลอกอัจฉริยะ

## **🌟 ฟีเจอร์เด่น (Key Features)**

* ✅ **Custom File Import:** รองรับไฟล์ .csv หรือ .txt ของคุณเอง  
* ✅ **Smart Randomizer:** ระบบสุ่มโจทย์และสุ่มตัวเลือกหลอก (Distractors) ไม่ให้ซ้ำกัน  
* ✅ **Instant Feedback:** แจ้งผล ถูก/ผิด ทันทีด้วยสี (เขียว/แดง)  
* ✅ **Real-time Scoring:** คะแนนขึ้นทันทีที่ตอบถูก  
* ✅ **Responsive UI:** ดีไซน์เรียบง่าย ใช้งานได้ทั้งมือถือและคอมพิวเตอร์

## **🛠️ เทคโนโลยีที่ใช้ (Tech Stack)**

* **Frontend:** HTML5, CSS3 (TailwindCSS)  
* **Logic:** JavaScript (ES6+)  
* **Data:** CSV / Text File Parsing
