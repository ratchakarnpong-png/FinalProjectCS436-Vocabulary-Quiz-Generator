1. Scope Document (ขอบเขตโครงการ)

Project Name: Vocabulary Quiz Generator (ระบบสร้างแบบทดสอบคำศัพท์อัตโนมัติ)

Objective (วัตถุประสงค์)

เพื่อพัฒนาระบบที่ช่วยให้ผู้เรียนสามารถทบทวนคำศัพท์ผ่านการทำแบบทดสอบแบบปรนัย (Multiple Choice) โดยระบบสามารถสร้างโจทย์และตัวเลือกหลอกได้อัตโนมัติจากไฟล์ข้อมูลที่ผู้ใช้นำเข้า

In-Scope (สิ่งที่ระบบทำได้)

File Import: รองรับการนำเข้าไฟล์คำศัพท์นามสกุล .csv หรือ .txt ที่มีรูปแบบ คำศัพท์,คำแปล

Quiz Generation:

สุ่มคำศัพท์มาเป็นโจทย์

สร้างตัวเลือก 4 ตัวเลือก (1 ถูก, 3 ผิด โดยสุ่มจากรายการคำศัพท์อื่นๆ ในไฟล์)

Scoring System:

ตรวจคำตอบทันทีเมื่อผู้ใช้เลือก

นับคะแนนและแสดงผลคะแนนปัจจุบัน (Real-time)

Result Summary: แสดงหน้าสรุปคะแนนรวมเมื่อทำครบทุกข้อ และมีปุ่มเริ่มใหม่

Responsiveness: รองรับการใช้งานผ่าน Web Browser บน Desktop และ Mobile

Out-of-Scope (สิ่งที่ระบบไม่ทำ)

ไม่มีระบบ Database (ข้อมูลจะหายไปเมื่อปิดหน้าเว็บ)

ไม่มีระบบ Login/Authentication

ไม่รองรับไฟล์มัลติมีเดีย (รูปภาพ/เสียง)

ไม่มีการเก็บประวัติการสอบย้อนหลัง (History Log)
